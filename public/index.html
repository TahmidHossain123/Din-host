Notice regarding free hosting limitations: This system runs on Render's Free Web Service. Local storage is strictly ephemeral. Whenever this service goes to sleep or restarts, deployed sites and data revert. Files must be re-uploaded. Permanent storage and 100% uptime are not supported under this zero-cost architecture.

Free Static Website Hosting Engine

Deploy lightweight client-side websites (HTML, CSS, JS, images) by packaging them into a standard .zip file with an index.html in the archive root.

Platform Technical Specifications

  • Upload Ceiling: 10 MB per ZIP bundle.
  • Decompressed Limits: 25 MB and 100 files max per project.
  • Execution Policy: Pure static assets only. Executable code (PHP, Node, Python, Shell) is forbidden and automatically rejected.
  • Subdomains: Path-based serving (/sites/:id/) functions immediately; direct subdomains require complete DNS routing.
